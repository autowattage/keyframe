# keyframe.hackclub.com
[Hack Club Keyframe](https://keyframe.hackclub.com) is a beginner-friendly program for teenagers 13-18. The premise is simple:
- Code an animation
- Post it online
- Win prizes!

The Keyframe website uses an MIT license. Use this website for whatever you want.
## Building
Keyframe's website is built on 11ty and hosted on Vercel.   

To run a local version of the Keyframe website, install 11ty:  
```npm install @11ty/eleventy```  

Then run the 11ty command:  
```npx @11ty/eleventy```  

Alternatively, run `npx @11ty/eleventy --serve` to get a live preview.
