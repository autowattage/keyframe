p5.js

p5.js is a Javascript library for making art and animations with code. They have a large community and plenty of documentation plus tutorials to help you get started!

  • p5.js Reference: Documentation for the p5.js library
  • p5.js Tutorials: Tutorials for p5.js!
  • p5.js Web Editor: An online web editor specialized for p5.js (you will need to record your time with Lapse)
  • OpenProcessing: The p5.js and Processing community. Has lots of great examples and inspiration!
